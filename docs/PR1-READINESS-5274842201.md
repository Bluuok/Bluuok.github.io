## 首页粒子

- 失败基线为 `d2f8dade`，远端 run `35684525632` 的强受力样本数为 0，四帧实际用时约 1417ms。
- 本地原样运行相同回归通过（2594 个强受力样本，约 28.3px），证据保留在本地 `review-output/ci-5274842201/baseline/`。这说明问题不能简化成“粒子物理必然没有效果”。
- 原探针在一个任务中注入整个 synthetic 轨迹，再等真实 RAF；软件渲染/CI 调度可能使下一次消费晚于轨迹的 250ms 有效期。新增过期输入负例：400ms 后消费，31 个样本全部被丢弃、强受力数为 0。它复现了失败机制；旧 CI 没记录输入诊断，无法事后证明其每个样本的具体丢弃时间。
- `pointer-input.ts` 将 coalesced event 时间跨度映射到显式模拟时钟。真实页面继续使用浏览器 coalesced events；没有修改冲量、阻尼、最大速度、粒子数量、粒径、材质或绘制质量。
- 浏览器回归分别运行 synthetic PointerEvent 与 Playwright trusted mouse，使用受控 RAF 时钟消除执行器往返和软件 GPU 的墙钟延迟。仍要求强受力速度 >80px/s、样本 >10、随后平均位移 >15px。
- `?scenePerf=1` 才记录输入诊断：trusted/synthetic 次数、每段长度/时间跨度/年龄、消费/丢弃数、前后速度 p50/p95/max。普通页面不排序统计速度。
- 本地最新对照：synthetic 2638 个样本、平均 34.95px；trusted 2509 个样本、平均 35.21px（256ms 模拟时间）。这验证输入和真实坐标更新，不是软件 GPU 或物理设备 60fps 的性能承诺。
