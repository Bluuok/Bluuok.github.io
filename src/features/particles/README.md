# 粒子调整说明

- `config.ts`：数量、实际光点半径、透明度与颜色；桌面基准 8200，移动端 2400，上限 10000。
- `interaction.ts`：鼠标吸引半径、力度、跟随速度。默认 attract 只拉动附近粒子；shape 可切换到跟随鼠标的预设图案。
- `renderer.ts`：细小彩色点与少量微光。白色背景不再依赖不可见的白色核心，也不再为每个点画大面积蓝灰光晕。
- `field.ts`：管理粒子运动和生命周期。开场仍通过既有 setScene/resetScene 接口传递进度与焦点；鼠标行为不依赖开场 DOM。

本次不改变首页布局、双手动画或项目内容。OpenDesign 本机 MCP 调用成功，但没有活动设计项目，未调用设计生成模型。
